Jev は最近人気が高まっています。Jev API は持っているけれど、まだ使い方がわからない場合は、このチェックリストをコピーするだけで済みます。1. jev-ultrafast は、Browser Use で構築された高速ブラウザエージェントです。Jev は各ステップで「何をするか、どの要素をクリックするか」のみを判断し、入力が必要な場合にのみ小さなモデルを呼び出します。Google Flights でフライトを検索すると、約 7 秒かかります。

https://github.com/browser-use/je超高速…

2\. fast-jev-compaction Claude Code のコンテキスト圧縮。ツール呼び出しの前に、Jev がまだ有用なものがあるかどうかを判断します。不要なものを削除し、元のテキストを書き換えずに保持します。

https://github.com/tamaratran/fast-jev-compaction…

3\. json-render Vercel LabsのジェネレーティブUIフレームワーク。実験では、JevはJSONトークンを1つずつ書き込むのではなく、コンポーネント、プロパティ、レイアウトの選択のみを処理します。

https://github.com/vercel-labs/jsレンダリング時…

4\. typesafe-mcp API を初めて使う人に最適です。Jev を Claude Code、Claude Desktop、Codex、Pi に接続して、いつでも Choice / Score / Noul を実行できます。

https://github.com/itsmostafa/typesafe-mcp…

5\. jev-mcp 既製のエージェント判断ツールキット：事実確認、コンテンツスクリーニング、意味的ランキング、分類、情報抽出。

https://github.com/jkudish/jev-mcp

6\. SemDecide Jevをコマンドラインツールに変換します。シェルで直接分類、スコアリング、フィルタリングを実行できます。クローラー、CI、データパイプラインとの連携に最適です。

https://github.com/sharziki/semde殺害…

7\. jev-codex-router まず、Jev にこのプログラミング タスクの難易度を判断させ、次にモデル ティア、推論深度、および速度モードを決定します。

https://github.com/0xNatoshi/jev-コーデックスルーター…

8\. Claude Code のコンテキストのガベージ コレクションの Winnow。Read / Bash / Grep が大量のデータを出力すると、Jev はまず現在のタスクに本当に関連のある部分を判断します。

https://github.com/GhalebDweikat/ウィンノウ…

9\. jev-review コードレビューの前に、まず Jev で実行してリスクの高い変更を特定し、その後、より高価な大規模モデルまたは人間に渡します。ローカルダッシュボードが付属しています。

https://github.com/devagrawal09/jev-review…

10\. Blink Jevをコードリポジトリナビゲーターとして使用します。各ディレクトリレベルで、現在の問題に最も関連のあるファイルを判断し、さらに深く掘り下げていきます。

https://github.com/ellipsis-dev/bリンク…

11\. agent-desktop デスクトップ自動化。システムのアクセシビリティツリーを読み取り、次にクリックするボタン、メニュー、または入力フィールドを判断します。

https://github.com/lahfir/agent-dデスクトップ…

12\. typesafe-mario Jevにスーパーマリオをプレイさせる。スクリーンショットは不要。エミュレータのRAMにある構造化された状態を読み取り、走る、ジャンプする、または回避するかどうかを判断する。

https://github.com/fhshaik/typesaフェマリオ…

13\. jev-drone Jevを使用してドローンを制御します。基本的な飛行制御は安定性と安全性を管理しますが、Jevは上昇、ブレーキ、障害物回避などのより高度な判断を行います。

https://github.com/RomanSlack/jevドローン…

14\. OneVOneJev ブラウザでプレイできる 1 対 1 FPS。あらゆる決定がティック単位で行われ、動き、視点、照準、射撃、ジャンプが判断されます。

https://github.com/emrickgarrett/OneVOneJev…

15\. jev-trader Monadテストネット上の高頻度マーケットメイキング。Jevはスプレッドと取引方向に基づいて次の買いまたは売りを判断し、モデルのレイテンシーは約81msです。

https://github.com/jarrodwatts/jevトレーダー…

16\. PrismはJevに直接注文を出させるわけではありません。毒性のあるフロー、市場の圧力、平均回帰などの状態を判断し、元の戦略に引き渡します。

https://github.com/irfndi/prism-l流動性エージェント…

17\. neo4jev Jevを知識グラフに組み込みます。各ノードで、次に取るべき最も価値のあるエッジを判断し、それを最後までたどります。

https://github.com/jexp/neo4jev

18\. jev-curate Jevを使用してトレーニングデータをスクリーニングします。JSONL / Parquetの場合、まず品質、関連性、リスクを評価し、次に次のトレーニングラウンドに進めるデータを決定します。

https://github.com/AkashPriyadarshii/jev-curate…

19\. Canny は、コーディング エージェントが頑固に完了したと主張するのを防ぎます。ツールの出力、コードの差分、テスト結果を確認し、完了の主張が信頼できるかどうかを判断します。

https://github.com/qkal/Canny

20\. killmyidea スタートアップのアイデアを入力すると、Jev が複数の角度から評価し、最終的に KILL、FIX、または SHIP のいずれかを出力します。

https://github.com/monteduro/kill私のアイデア…
